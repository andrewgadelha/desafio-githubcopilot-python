# Desafio Resolvendo Códigos em Python com o Github Copilot - DIO.me
----------------------------

## Exercícios de Python com GitHub Copilot

Este repositório reúne exercícios introdutórios de Python feitos como parte de um desafio da DIO. **O objetivo principal foi praticar o uso do GitHub Copilot como apoio durante o desenvolvimento**, explorando sugestões de código e aprendendo a avaliar, adaptar e compreender o que foi sugerido.

O Copilot é um assistente: suas sugestões devem ser revistas e entendidas por quem está programando. A proposta também é praticar os fundamentos de Python enquanto se experimenta essa ferramenta.

### Exercícios

Os exemplos estão na pasta [`resolucao/`](resolucao/):

| Arquivo | O que pratica |
| --- | --- |
| [`concatena.py`](resolucao/concatena.py) | Receber dois textos e juntá-los em uma string. |
| [`repete.py`](resolucao/repete.py) | Repetir um texto a quantidade de vezes informada. |
| [`simples_opera.py`](resolucao/simples_opera.py) | Escolher entre soma, subtração, multiplicação e divisão. |
| [`verifica_par_impar.py`](resolucao/verifica_par_impar.py) | Verificar se um número inteiro é par ou ímpar. |
| [`media.py`](resolucao/media.py) | Calcular a média de três notas. |
| [`palindromo.py`](resolucao/palindromo.py) | Verificar se um texto é um palíndromo. |

### Como executar

Com Python instalado, abra o terminal na pasta do projeto e execute o arquivo do exercício desejado. Por exemplo, no Windows:

```powershell
py .\resolucao\concatena.py
```

Troque `concatena.py` pelo nome de outro arquivo da tabela para executar um exercício diferente. Os programas que solicitam dados vão pedir as entradas no próprio terminal.

### Conteúdos praticados

- Entrada e saída de dados com `input()` e `print()`
- Strings, concatenação e repetição
- Conversão de valores com `int()` e `float()`
- Operadores aritméticos e operador módulo (`%`)
- Condicionais (`if`, `elif` e `else`)
- Funções e manipulação de strings
- Uso do GitHub Copilot como apoio ao aprendizado de programação
